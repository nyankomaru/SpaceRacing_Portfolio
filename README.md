# SpaceRacing_Portfolio

疾走感と宇宙らしさにフォーカスした、ロケットで宇宙空間を駆け抜けるレースゲームです。

このリポジトリでは、チーム制作内で自分が担当・改修したスクリプトを中心に掲載しています。  
実行データはGitHub Releasesからダウンロードできます。

---

## 概要

SpaceRacingは、プレイヤーがロケットを操作し、宇宙空間のコースを高速で進みながらゴールを目指すレースゲームです。

プレイヤーの進行状況を自然に表示するためのSplineベースの進行度UI、操作に応じて変化するAudio制御、BGM管理、ゴール判定処理などを担当しました。

また、プログラム以外にも、概要書・仕様書作成、ロゴデザイン制作、進行管理を担当し、チーム全体の制作進行にも関わりました。

## 実装上の工夫

### 進行度UI

レースゲームでは、プレイヤーが現在どの程度進んでいるかを自然に把握できることが重要です。

Spline上の最近点から距離を取得し、コース全体に対する進行度を算出する仕組みを実装しました。

また、別区間への吸い込みによる値飛びを抑えるため、表示用の進行度を補間し、最大到達距離を保持することで、逆走時にゲージが不自然に戻らないようにしています。

---

### Audio制御

操作と一体化した疾走感を出すため、プレイヤー入力に応じてエンジン音や回転音が変化する仕組みを実装しました。

推力入力や回転入力を0～1の値として扱い、`FInterpTo` によって滑らかに補間した上で、音量やピッチへ反映しています。

低域エンジン音、高域エンジン音、回転音を分けて管理することで、速度感や操作感を音でも伝えられるようにしました。

---

### BGM管理

BGMの再生・停止・切り替えを専用のActorに集約しました。

`UAudioComponent` を用いてBGMを一元管理し、フェードイン・フェードアウトに対応しています。  
毎フレーム更新が不要なためTickは無効化し、必要なタイミングで再生・停止・切り替えを行う設計にしています。

---

### ゴール判定

ゴール判定にはBoxトリガーを使用し、Actorが侵入したタイミングでBlueprint側のゴール処理を呼び出せるようにしています。

C++側ではOverlap判定とタグ取得を担当し、実際のゴール演出やリザルト処理はBlueprint側で拡張できる構成にしました。
